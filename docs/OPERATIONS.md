# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。工作台的“本次已签范围”显示水位以内的记录，“签收与结转”显示待处理记录和签发取舍。
3. 修复来源文件，重新上传并执行。历史批次保留供复核；“旧签结果”显示同一批业务分组更早批次的意见。
4. 对账无差异且无阻断记录时可签发。仅有结转事件时按交接时限决定是否按时签发；仍有阻断记录只能填写暂缓意见。要等齐迟到事件时，提高分区水位后重跑，结果与一次性全量重放一致。
5. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。
